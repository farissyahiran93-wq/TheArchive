`E001+E002 → E012+E003 → K02` is version proof, not motive. `E013+E014+E009 → K05` supports movement/order without GPS. `E008+E018 → K08` records public CO harm without private chart. `E009+E015+E019 → K13` matches Vivian authority, while `E010/E015 → K12` holds Daniel accountable for publication. `E020 → K14` means a signed acknowledgment, never merely submission.
