## Explicit adverse-branch trace and scene exit rules

1. **Anonymous tip:** source Bulletin listing → player composes and presses Send → R01 records anonymous mode/token → reply stays in token inbox → opt-in denied leaves Messages closed → E012 request still available → player may finish E01; Maya knows tip text only. **Handle tip:** same sequence with a handle field; Maya knows the chosen handle, not verified legal identity. Silence/skip means no R01 or implied reply; public investigation still continues.
2. **Archive declined:** S17 decline sets `offer.archive.e01 = declined`, not `workspaceAccess = true` and not R03. S18 tours only if accepted. S19 displays permitted public preview without a private card; E003 and E012 proceed. Player may accept later explicitly. No mandatory evidence is lost.
3. **Low trust, no romance, Ana refuses:** retain unintroduced/contacted distinctions and zero romance; obtain E013/E014 from distinct custodians, E012 through GCRO, E015 through historical work-order custodian. Ana's name stays sealed. Character relationship cannot authorize any record. If a custodian refuses, the corresponding knowledge flag remains pending and an appeal/alternate source is shown rather than silently granting it.
4. **Device found; independent welfare succeeds or fails:** record the device lead without K11; counsel challenge and second-channel check precede signed attestation. On success, R12 to Sophie contains only the exact dated alive/able-to-respond statement. On failure/absence, S11 says pending, no R12, no location, and the preservation investigation uses records without Daniel direct contact.
5. **Pause or direction denied/delayed:** an ordinary player files the sourced challenge, CRCU/GIRRO—not the player—exercise power. A pending filing cannot stop disposal. The proposed record-only GIRRO emergency route is explicitly **unapproved**; until approved, deny the pause and block optimistic E020, while retaining a truthful pending/denied outcome. E020 requires both an effective GIRRO direction and CRCU acknowledgment before the deadline.
6. **Unknown credential operator:** show only sourced capability, not user identity. E09 compares historical E015/E019 and E009; Daniel's publication is distinct from Vivian's approval. If operator attribution is still absent, the ending says it is unknown. **Fresh and returning players:** restore only persisted knowledge and permissions; a draft tip, invitation or source request is not a sent message, granted access, verified fact or receipt.

**Conclusion:** T04 and T08 pass narrow documentary invariants. T07's successful denial branch is blocked; the remaining seven tests are partial. This packet defines traces for a future versioned manifest and playable validation, not a Phase 02 entry pass.
