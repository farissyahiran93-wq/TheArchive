## Shared chain, privacy and failure rule

Each final asset must name the *original* holder, request/legal-fictional basis, authorized reader, source index, scan/copy revision, custodian/signature and separately checkable roster, page count/completeness (including **explicit missing-page statement**), redaction fields/reason, transfer time/channel/recipient, and actual asset digest if a byte-level artifact exists. A digest checks transfer integrity, not truth or completeness. No officer, signature, exact code crosswalk or source bytes are invented by RC1.

If full pages cannot be released, the **same original custodian** may issue a certified, source-indexed summary with what was searched, pages covered/missing, its limits and a transfer receipt. Label it `CERTIFIED_SUMMARY`, not an original second source. A missing page, unverified code mapping or denied release removes the negative-intake inference. One remaining source can support only its own narrower claim; absence from a log alone never proves a person was absent at a place. Independent E006/E018 and, if lawfully obtained, E009 can add context, but cannot repair a fictitious E013/E014 issuance. R07 shares only selected route findings with named recipients. No optional romance/trust action grants a record.
