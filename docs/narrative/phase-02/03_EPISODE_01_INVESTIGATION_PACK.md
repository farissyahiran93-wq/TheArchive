## Source and uncertainty rules for implementers

1. Each source card displays publisher, original holder, version, date, reader scope and limit. A cached page is not an issued export. A correct puzzle gesture cannot promote an invalid source.
2. `E012.valid` requires **real final delivered-file integrity**, independent issuer roster check, matching lineage, complete four pages/redaction, and requester transfer. The 2,012-byte UTF-8 authored master has SHA-256 `887c59c42ea8b375737b78a3e79ae0d8d57da7c8698e7e21adea955136d730de`; this is a development integrity value, not a fictional GCRO signature or a runtime check. If the delivered format changes, hash those delivered bytes for the issue envelope. The prose here does not substitute for production verification.
3. Search uses exactly the four authored local result IDs and query aliases in S01. If a player enters arbitrary words, return the authored no-result line and offer record/year/office synonyms. Do not secretly reveal future assets via suggestions.
4. Maps contains only named public places in M01. Its pins do not prove 2019 route movement or Daniel location. It is optional context and cannot gate K02.
5. Hints are progressive per scene but can be requested directly by accessibility setting. Wrong answers preserve source access and comparison state. No mandatory timed or precision gesture.
