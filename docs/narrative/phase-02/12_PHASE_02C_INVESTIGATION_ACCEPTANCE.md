## Source failure and recovery decisions

| Variant | Authored state/result | Route back to progress |
| --- | --- | --- |
| S27 review pending, overbroad scope or refusal | Request receipt proves review only. E012/R04/K02 absent; no S30 finale. | Narrow/resubmit or seek recorded review. A refused release is not proof June was absent. |
| One-use token invalid/replayed | No export delivered and no R04. | Open request recovery; a new eligible request must receive its own receipt. |
| S28 late issue | Public comparison stays `LEAD` until a genuinely delivered issue is checked. | Reopen S28 at actual later receipt; prior public timestamps are not rewritten. |
| Wrong issuer, lineage, page/redaction, recipient or byte integrity | File quarantined as `ISSUED BUT UNVERIFIED`; seeing June on Page 2 cannot create K02. | Request corrected release/new revision; perform all checks again. |
| S29 citation draft unsaved | No K02 even if cards are placed correctly. | Tap **Save corroborated finding** once with valid R04. |
| S30 role card stale/missing rule | No enabled-role fact; process notice yields narrower question. | Episode may end only after K02 and R01/S12, with fallback wording. |
