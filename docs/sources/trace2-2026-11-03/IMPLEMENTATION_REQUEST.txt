C. Tracker — cinematic but credible
- On INDEX ADDED TO TRACE, open the actual TRACE app to Tracker and begin first-run analysis (or provide an immediate single clear start action if required by existing story gate).
- Stage sequence: INITIALIZING → INDEX LOOKUP → FIELD MATCH → VERIFYING SOURCE LIMITATIONS → COMPLETE.
- Animate a progress bar, rotating/scrolling terminal logs, activity heartbeat, and a small reference-node graph (local index → public ID match; missing original content + unverified revision remain distinct unresolved nodes).
- Use contextually meaningful simulated logs such as:TRACE ENGINE // LOCAL INDEX
  [INIT] Opening recovered reference store...

  [MATCH] Public article reference: GB-ARTICLE-001
