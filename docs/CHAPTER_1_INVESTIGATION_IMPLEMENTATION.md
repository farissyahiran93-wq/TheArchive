# Chapter 1 investigation implementation

The audit found an existing TRACE recovery viewer, a persistent Case File 001 and Investigation Board, and authored investigation sources and calls through Scene 10. Scene 5 could save a fragment immediately after opening it. Scene 6 could save its gap after opening the two records. Scenes 7–10 still required several inspection, import or review controls. This change reuses those sources and workflows and replaces those steps with an observation, a comparison or a supported finding.

| Scene | Player activity and milestone |
| --- | --- |
| 1 · A Message from Sophie | Continue the original conversation and establish Daniel’s disappearance. |
| 2 · The Uninvited Guest | Continue the group conversation, privacy dispute and handoff to Sophie. |
| 3 · Just Between Us | Continue Sophie’s private account of Daniel and the existing handoff to Unknown. |
| 4 · The Unknown Sender | The latest 12-turn script retains three options per decision and explicit Send. One reply arrives after the dots-only typing indicator. The tool preview precedes manual entry into Scene 5. |
| 5 · The Digital Archive | Install TRACE, open a fragment and highlight a relevant detail or compare two fragments. Save an observation with its limitations, then discuss it. First-pass recovery is 12%. |
| 6 · The Missing Hour | Compare the file access and automatic sync records to document the unexplained interval. Ordering, flags, hypotheses and board links are available. Recovery reaches 20%. |
| 7 · The Starred Number | After Sophie’s call, compare her account with the masked contact export. Save a corroborated detail or leave the source or damaged remark unresolved. |
| 8 · The Last Check-In | Compare Maya’s crop with her account, the earlier export or Lucas’s available testimony. Save what the sources support and leave missing context open. |
| 9 · The Secondary Card | Examine the supplied photo, identify its visible reference and compare it with an earlier source. Save a provisional finding to make the code available for inventory lookup. |
| 10 · The Inventory Sheet | Compare the matching public entry with Maya’s photo. Review Case File 001 and the Board, then save a private theory with supporting clues and an outstanding question. The original call follows when the player returns Home. |

Case File 001 adds questions as sources become available. The Board shows discovered clues and documented findings, with side-by-side comparison, zoom, drag and keyboard position controls. Player-created relationships start tentative and can be labelled, revised or removed. A player’s label never changes a source’s authenticity. Case notes support an alternative explanation and counterevidence, and Scene 10 saves its investigation summary in the same case.

Earlier saves retain their delivered dialogue and valid findings. Existing Scene 5 and Scene 6 progress remains compatible, and an active historical Scene 10 inventory sequence can finish through its original controls. Replaying a scene requires explicit confirmation before replacing the active save. Scenes 7–10 leave phone recovery at 20%.
