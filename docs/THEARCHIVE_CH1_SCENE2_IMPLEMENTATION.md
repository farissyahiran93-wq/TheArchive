# Chapter 1 Scene 2 — implementation report

The new campaign's existing chat runner uses the separate `TA-S02-*` graph in `src/content/masterScene02.ts`. It starts only when the player opens FIND DANIEL after Scene 1's explicit JOIN. Nine choice points each provide three player responses and branch-specific character replies; all player messages require Send. The implemented dialogue is exported in [the screenplay](THEARCHIVE_CH1_SCENE2_SCREENPLAY.md).

Sophie, Maya and Lucas start as members. Sophie attributes the contact export to Daniel's shared folder, without claiming to know the origin of the star. After the eighth choice, Lucas's authored departure changes membership and appends the once-only system line “Lucas Grey left the group.” Previously delivered group messages and recipient receipts remain in history. The group completes after the ninth choice; its saved 5.5-second handoff delivers Sophie's private message once and only then records `TA-S02-SCENE03-UNLOCKED`. The player must open the DM manually. The new route deliberately does not start Scene 3.

The existing scene state persists cursor, draft, history, membership, queue, choice receipts and handoff. `masterScene01` selects the new graph; saves without that marker remain on their previous graph. Existing code in `src/game/scene01.ts` handles entry, actor-specific delivery, membership, messaging and handoff. `src/game/sceneLibrary.ts` treats the new Scene 2 as complete only after the DM is delivered. The group chat UI reports the subsequent boundary without exposing Scene 3 dialogue.
