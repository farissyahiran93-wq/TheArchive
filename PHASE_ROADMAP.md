# Production phases

| Phase | Output | Exit evidence |
|---|---|---|
| 00 | Reboot workspace, typed engine, local save, phone shell, non-canonical fixture, basic Search/Maps, docs | Typecheck, lint, unit, build, mobile browser and refresh checks |
| 01 | Canon reconciliation and playable opening vertical slice | Approved Story Bible v2 mapping, authored scene graph, knowledge audit, human playtest |
| 02 | Evidence comparison, timeline reconstruction, case file, richer communication | Puzzle comprehension, save migration and branch tests |
| 03 | First full episode production pipeline | Episode 1 complete with pacing and accessibility playtest |
| 04+ | Incremental episode production, Android packaging, performance and device QA | Episode-specific gates and release criteria |

Do not schedule content at 2.5–4 hours per episode until a representative vertical slice is timed with real players. Each phase should freeze and review event IDs and save migrations before authoring more content.
